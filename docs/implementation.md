# 实施与验证范围

本项目使用 C# / .NET 10 / WPF，包含桌面助手、短命 CLI、本地命名管道、持久收据及只读 Codex 适配。目标协议版本为 Codex 0.165.0。

| 范围 | 已完成的检查 |
| --- | --- |
| 时间与完成语义 | 299 / 300 / 301 秒边界；真实长任务报告、新短任务跳过；超过十分钟但仍等待、暂停或失败时不报告完成 |
| 返回任务 | 同目录两个真实线程的原视图关闭后，分别从卡片和历史返回；线程、实例、目录和原上下文匹配，不创建新轮次 |
| 列表与存储 | 主任务筛选、分页、失败保留快照；3 天 / 20 项保留、重复与冲突、保存失败、丢失 ACK 后恢复 |
| 窗口交互 | 居中、原尺寸、拖动、位置记忆、点击外部关闭并透传、托盘恢复、Tab / Esc、焦点恢复 |
| 动画与全屏 | 同一窗口展开与收回；修复首次展开闪烁；全屏时收回摘要、保留入口，恢复不补播 |
| 主题 | 原有控件动态换色，保留页面和未保存设置；受控高对比配色；实际按钮悬停对比度 |
| 运行与分发 | Release 构建、隔离安装卸载、自包含目录解压启动；冷／热投递、静置 CPU 和面板内存测量 |

核心存储检查可通过 `tests/RemindAtDone.Tests` 重跑。主题回归通过 `tests/RemindAtDone.UiTests` 在隔离数据目录运行。更多集成检查需要依据脚本参数准备环境。

## 已知边界

- 当前为开发预览，不宣称锁屏恢复、100%–200% 实际缩放切换或物理拔屏已全部实测。
- 受控高对比配色测试不等于操作系统高对比模式的完整兼容性验证。
- 原开发环境的长期观察在约五小时后停止，没有把它记作完整工作日验收。
- 性能数据受硬件、系统负载和 daemon 状态影响。协议及资源预算不是对所有环境的保证。
- 发布仓库不包含个人配置、会话记录、原始截图、录屏、构建目录或开发过程的内部记录。
